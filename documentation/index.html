MinGW & First C Program

Beginner Friendly
Seemol Chakroborti | wpseemol@gmail.com | wpseemol wpseemol

This guide walks you through installing MinGW (Minimalist GNU for Windows) and compiling your very first C program — “Hello, World!” — right from the command line. No prior experience needed!

Step 1 — Download MinGW

STEP 1.1

Go to the official MinGW website: sourceforge.net/projects/mingw/
Click the green “Download” button. This will get you the mingw-get-setup.exe installer.

STEP 1.2

Run the installer. When asked, choose the installation directory (the default C:\MinGW is perfectly fine).
Remember this path — you'll need it for the environment variable.

Step 2 — Install Essential Packages

STEP 2

After the installer finishes, the MinGW Installation Manager will open. Do this:

  • Find mingw32-gcc-g++ under Basic Setup.
  • Right-click it and select “Mark for Installation”.
  • Also mark mingw32-gdb (debugger) — optional but helpful.
  • Click “Installation” in the top menu → “Apply Changes”.

This may take a few minutes. Wait until it finishes.

Step 3 — Add MinGW to PATH

STEP 3

To use gcc from anywhere in the command line, you must add MinGW's bin folder to your system PATH environment variable.

🔹 Windows 10 / 11

  1. Press Win + R, type sysdm.cpl and hit Enter.
  2. Go to the Advanced tab → click “Environment Variables…”.
  3. Under System variables, scroll and select Path → click “Edit…”.
  4. Click “New” and paste the path to MinGW's bin folder, e.g.
    C:\MinGW\bin
  5. Click OK on all windows and restart your terminal (or your computer).
Pro tip: To verify the PATH is set correctly, open a new Command Prompt and type gcc --version. You should see version information — not an error.

Step 4 — Write Your First C Code

STEP 4

Open any text editor (Notepad, VS Code, or even Notepad++) and create a new file. Copy and paste the classic “Hello, World!” program:

copy // hello.c — my first C program
#include <stdio.h>

int main() {
    printf("Hello, World! \n");
    return 0;
}

Save the file as hello.c in a folder you can easily find, for example C:\my_c_projects\.

Step 5 — Compile with MinGW (gcc)

STEP 5

Open Command Prompt (or PowerShell) and navigate to the folder where you saved hello.c.

cd C:\my_c_projects

Now compile your program using the gcc command:

gcc hello.c -o hello.exe

This creates an executable file named hello.exe. If you see any error messages, double-check your code for typos.

Tip: The -o flag specifies the output file name. You can name it anything, e.g. -o myapp.exe.

Step 6 — Run Your Program

STEP 6

In the same terminal, type the name of your executable and press Enter:

hello.exe

You should see the glorious output:

Hello, World!

Congratulations! You've just compiled and run your first C program using MinGW. 🎉

Quick Command Reference

Command What it does
gcc --version Check if MinGW is installed and in PATH
gcc hello.c -o hello.exe Compile hello.c into hello.exe
hello.exe Run the compiled program
gcc -Wall hello.c -o hello.exe Compile with all warnings enabled (good practice)

Common Issues & Fixes

“gcc is not recognized as an internal command” — This means the PATH was not set correctly. Go back to Step 3 and ensure you added C:\MinGW\bin (or your custom path) to the System variables Path, then restart your terminal.
“stdio.h: No such file or directory” — You may have missed installing the gcc package in the MinGW Installation Manager. Re-open the manager and make sure mingw32-gcc-g++ is marked and installed.
Antivirus / firewall warning: Some antivirus software may flag MinGW or your compiled .exe files. This is a false positive — you can safely add an exception.
