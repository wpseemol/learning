## 🗺️ Learning Roadmap

1. **Basics**
    - History & characteristics of C
    - Setting up a compiler (GCC, Clang)
    - “Hello, World!” and compilation process

2. **Fundamentals**
    - Variables, data types, constants
    - Operators and expressions
    - Control flow (`if`, `switch`, loops)

3. **Functions & Scope**
    - Function declaration/definition
    - Parameters and return values
    - Scope and storage classes

4. **Arrays & Strings**
    - One‑dimensional and multi‑dimensional arrays
    - String handling (`<string.h>`)

5. **Pointers** – _the heart of C_
    - Pointer arithmetic
    - Pointers and arrays
    - Pointers to functions

6. **Dynamic Memory Management**
    - `malloc`, `calloc`, `realloc`, `free`

7. **Structures & Unions**
    - Defining and using `struct`, `union`
    - Nested structures, pointers to structures

8. **File I/O**
    - Reading/writing text and binary files

9. **Preprocessor & Macros**
    - `#define`, `#include`, conditional compilation

10. **Advanced Topics (future)**
    - Bitwise operations
    - Recursion
    - Linked lists / basic data structures
